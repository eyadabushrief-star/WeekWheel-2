# WeekWheel Android

تطبيق Android مستقل لعجلة أيام الأسبوع.

## التشغيل
1. افتح المجلد `WeekWheelAndroid` في Android Studio.
2. انتظر انتهاء Gradle Sync.
3. اختر `app` ثم شغّل التطبيق على هاتف/محاكي.
4. لبناء APK: `Build > Build APK(s)`.

الحد الأدنى Android 6.0 (API 23).
التطبيق يعمل دون اتصال بالإنترنت بعد البناء.
